# Architecture (human-readable)

What Ten is, how the pieces fit, and how to run it. Confirmed facts only. Dense agent detail lives in `scaffold/ARCH-LLM.md`. Lessons/traps live in `scaffold/PROJECT-KNOWLEDGE.md`. Word-pool editorial rules live in `scaffold/generating-words.md`.

## What it is

**Ten** — a personal phone-first web app (PWA) for learning **Brazilian Portuguese** and **Quebec French**. You study 10 words a day, translate anything, review flashcards in Anki, and track which frequency-list words you’ve unlocked.

One user only. No accounts, sharing, or multi-user design.

```
  Phone (Tailscale)              Backup MacBook (always on)
        │                                │
        ▼                                ▼
   Ten in browser  ──────HTTP──────►  Node server
   (vanilla JS PWA)                      │
                                         ├── static files (src/client)
                                         ├── /api/translate ──► Google (1–5 words) or DeepL (6+)
                                         ├── /api/anki ───────► AnkiConnect (local Anki)
                                         └── SQLite (unlocks + today’s card position)
```

## Main tabs

| Tab | What you see |
| --- | --- |
| **10/day** | Ten fixed words for today from the active language pool, with translations and example sentences. Remembers which card you were on. Confetti once when you finish the tenth (per language per day). Opens first on refresh unless you already finished today — then Translate opens. |
| **Translate** | Type text; short inputs use Google Translate, longer ones use DeepL. Save to Anki; hear TTS. Single-word lookups also unlock that word on the Frequency tab and show rank when known. |
| **Review** | New and due Anki cards (new first). Grades go straight back to Anki. |
| **Frequency** | Bundled top-frequency lists. Unlocked words light up green. **Unlocked** and **Not learned** summary cards filter the list (tap again to show all). Tap a word for an inline translation. |

Language switch (Brazil / Quebec) is top-right. Default on open is French. Each language has its own Anki deck and note type (`Basic-BR` / `Basic-FR`) so duplicates don’t collide across languages.

## How the system is built

One small Node server does everything: serves the PWA files and proxies translate + Anki.

| Piece | Job |
| --- | --- |
| `src/client/` | The whole UI (HTML/CSS/JS). No React or build step. |
| `server/index.js` | Serves files + `/api/*`. |
| `server/db.js` | SQLite: unlocked frequency words and which 10/day card is open today. |
| `src/client/words.*.json` | Daily word pools (Portuguese is generated by script; French from frequency lists). |
| `src/client/frequency-*.json` | Static frequency dictionaries. |
| Anki Desktop + AnkiConnect | Real flashcards and scheduling. |

## Run it locally

```bash
cd /path/to/ten
cp .env.example .env    # set GOOGLE_TRANSLATE_API_KEY and DEEPL_AUTH_KEY
npm install
npm run start           # http://localhost:3001 by default (scans up if busy)
npm run deepl:check
npm run google:check
```

## Production (backup MacBook)

Needs: Anki Desktop running with AnkiConnect, Ten’s Node server, internet for translate APIs, and the two API keys.

**One-time Anki setup:** Tools → Manage Note Types → clone `Basic` twice; name them exactly `Basic-BR` and `Basic-FR`.

**Phone access:** Tailscale on the MacBook and phone (same tailnet). Open `http://<tailscale-ip>:3001` (or whatever port the server printed).

**Keep it running (launchd):** example plist at `~/Library/LaunchAgents/com.ten.app.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.ten.app</string>
  <key>ProgramArguments</key>
  <array>
    <string>/bin/zsh</string>
    <string>-lc</string>
    <string>cd /path/to/ten && npm run start</string>
  </array>
  <key>RunAtLoad</key>
  <true/>
  <key>KeepAlive</key>
  <true/>
  <key>StandardOutPath</key>
  <string>/tmp/ten.out.log</string>
  <key>StandardErrorPath</key>
  <string>/tmp/ten.err.log</string>
</dict>
</plist>
```

```bash
launchctl load ~/Library/LaunchAgents/com.ten.app.plist
```

**After code updates:** `git pull && npm install`, then restart the launch agent if needed.

**Back up** `data/ten.db` (or whatever `TEN_DB_PATH` points at) — that file holds unlocks and daily progress.
